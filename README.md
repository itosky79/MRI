# MRI スピン3Dシミュレーター

### ▶ **[https://itosky79.github.io/MRI/](https://itosky79.github.io/MRI/)**

ブラウザで開くだけで使えます。インストールもログインも要りません。スマートフォンでも動きます。

---

T1強調画像・T2強調画像が「なぜそう写るのか」を、体の中のプロトンのスピンまで戻って追えるシミュレーターです。
静磁場の中で歳差運動しているスピンに **どういう力（RFパルス）を、どのタイミングでかけるか** を決めると、
そのスピンがどう倒れ・どうばらけ・どう戻るかが 3D で動き、その結果できあがる画像が横に出ます。

`index.html` と `three.min.js` の 2 ファイルを同じ場所に置いて、`index.html` をブラウザで開くだけで動きます。
three.js は CDN から読まずに同梱しているので、外部への通信は一切必要ありません。

## 画面の構成

大事な図は3つで1組です。この3つがスクロールなしで同時に見えるように並べてあります。

- **① 3D** — 体の中のプロトンが、いまどうなっているか
- **② パルスシーケンス** — いつ、どんな力（RFパルス）をかけているか
- **③ 緩和曲線とコントラスト** — その結果、組織の差がどこで開くか
- **④ 矢印から画像へ**（コンソールの中） — その矢印が、画像のどの明るさになるのか

どれか1つを変えると4つとも同時に変わります。右のコンソールで条件を決め、この4つで何が起きたかを読みます。
画像は3Dの右上に出ます（「3Dだけ」にすれば消せます）。

### 受信コイルと電磁誘導

「横磁化が信号になる」が言葉だけにならないように、**受信コイル**（輪）を3Dに出せます
（「表示と操作」の *受信コイルを出す*、または学習の「原理」⑤⑥で自動的に出ます。静止座標系・1つのボクセルのときだけ）。

実際の受信コイルが体を囲むのと同じく、**輪は磁化のまわりを囲んで**います。輪の面の法線は y 軸です。

- **輪を貫いている分**（＝磁化の y 成分）が紫の矢印と数字で出ます。Mxy の先から y 軸へ下ろした破線が、その「成分」です。
- 磁化が回ると、貫く分が **+ → 0 → − → 0 →** と増えたり減ったりします。
- その**変化の速さ**（|dΦ/dt|）に応じて**コイルが青緑に光ります**。これが起電力 `V = −dΦ/dt`、つまり MRI の信号です。
  貫く分が最大のときはコイルが暗く、0 を横切る瞬間がいちばん明るい、というのもそのまま見えます。
- 熱平衡（縦磁化だけ）では貫く分は 0 のまま動かないので、コイルはずっと暗いままです。**だから一度倒す**、が目で見えます。

コイルを出しているあいだは、**細い矢印（虹色）・Mz・Mxy・軌跡をすべて消します**。
見てほしいのは「回る磁化 M（青緑）」と「輪を貫く分（紫）」の2本だけで、色が増えると焦点がぼけるためです。
コイルが光る色も紫に合わせてあります。

「原理」⑤⑥では、**消えにくい組織（脳脊髄液）＋均一な磁場**に自動で切り替え、歳差も速めに見せて、
T2 で消える前に何周も回るようにしています。④の RFパルスは**3秒ほどかけてゆっくり**倒すので、
B₁（オレンジ）が一瞬で消えずに見られます。

### ④ 矢印から画像へ

3Dの矢印と画像のあいだが、いちばん飛びやすいところです。④ には組織ごとに1行ずつ、

> 組織名 ｜ **横向きの長さ × プロトン密度** の棒 ｜ その数値 ｜ その明るさの四角

が並びます。棒の長さは 3D の矢印に付いている数字そのもの、四角の色は画像に出る灰色そのものです。
**「組織ごとに塗ってみる」**を押すと、画像が真っ黒から始まって、脂肪 → 白質 → 灰白質 → 脳脊髄液 と
1組織ずつ塗り足されていきます。塗っている組織は、3Dの矢印と ④ の行が同時に光ります。
「矢印1本が、画像のどの画素になったのか」をそのまま見られます。

## 4つのタブ

- **シーケンス**（最初に開くタブ） — T1強調SE／T2強調SE／プロトン密度／T2*強調GRE／T1強調GRE／STIR／FLAIR／強いT2強調 を1押しで切り替えます。
  プリセットの下に **TR と TE のつまみ**があり、動かすとその場で3つの図と画像が変わります。
  使わないつまみ（IR のときだけの TI、GRE のときだけの α）は並びません。
- **学習** — 読む教材ではなく、**押して見る案内**です。はじめてのチュートリアルと同じで、
  画面の該当する場所だけが光り、短いカードが「次へ」で進みます。**文章は各手2行まで**。
  読む時間より、押して動かす時間のほうが長くなるようにしてあります。
  **原理と撮像法は別の話**なので、はじめから2つのコースに分けてあります。
  - **「原理」コース（11手）** — なぜ信号が出て、なぜ消えるか。撮像法の名前は出てきません。
    ①静磁場の中のプロトン（薄い矢印で M₀ も見せる）→ ②足し合わせると1本の矢印（押すと、水素の矢印が集まって
    同じ大きさの M になる）→ ③脳のどこにも M がある（脳の断面いっぱいに上向きの M を敷き詰める）→
    ④RFパルスで倒す → ⑤どうやって信号になるのか（電磁誘導）→ ⑥縦磁化だけでは信号は出ない →
    ⑦T2 → ⑧T2* → ⑨スピンエコー → ⑩T1 → ⑪まとめ（S = ρ × T1 × T2）

    ①〜③は「プロトン1個 → 1つのボクセルの M → 脳全体」とつながるように作ってあります。
    ①の薄い M₀ と②の M は同じ大きさで描き、ここに描いた30本の水素はほんの一部であること
    （1 mm³ の水でおよそ 10²⁰ 個）を②で言葉にしています。
  - **「撮像法」コース（7手）** — その原理を使って、T1強調・T2強調…をどう作るか。
    ①矢印から画像へ → ②TR → ③TE → ④3枚ならべて見る → ⑤GRE → ⑥IR（STIR） → ⑦FLAIR

  各手でシミュレーターの条件が自動で切り替わります。多くの手に**その場でやってみるボタン**があり

  「3枚つづけて撮る」など）、押すと実際に 3D と画像が動いてから「次へ」に変わります。
  「① から順に」で頭から、下の一覧からは好きなところから始められます。いま何手目かは一覧に印が出ます。
- **詳細** — シーケンスの種類（SE / GRE / IR）、静磁場強度（0.5 / 1.5 / 3.0 T）、静磁場のムラ（T2′）、
  そして**手でパルスをかける**ボタン。手動にすると自由歳差だけが進むので、
  **90° → 少し待つ → 180°** と押して、自分の手でスピンエコーを作れます。
- **問題** — 診療放射線技師国家試験の過去問 18 問（第62回 午前 第23問、第63回 午前 第19問、第65回 午前 第32問、第67回 午後 第15問、第67回 午後 第17問、第68回 午後 第74問、第69回 午前 第11問、
  第69回 午後 第74問、第70回 午後 第15問、第71回 午後 第12問、第73回 午前 第74問、第75回 午前 第24問、第75回 午後 第11問、第76回 午前 第12問、
  第76回 午後 第15問、第77回 午前 第64問、第77回 午後 第7問、第78回 午後 第64問。
  厚生労働省 公表、正答は正答値表で確認）。出典は問題ごとに「第◯回 診療放射線技師国家試験 午前／午後 第◯問」と出ます。
  スピンの動き（倒れ方・戻り方・減り方・反転・共鳴周波数）を見て確かめられる問題だけを選び、開くと問題の撮像条件になります（答えにあたる値は設定しません）。
  手元の過去問は「問題を入れ替える」から貼り付けて差し替えられます。「設定」を書いておくと、

## 初学者向けの手当て

- 3Dの下に**色の凡例**（細い矢印＝スピン1本ずつ・太い矢印＝合計の磁化 M・緑＝Mz・赤＝Mxy）
- 3Dの左下に「**いま何が起きているか**」を一文で表示（90°パルスで倒している／位相がばらけて信号が減っていく／エコー：ここで信号を読む など）
- パルスシーケンス図のRFに「**倒す**」「**位相をもどす**」「**縦磁化を反転**」、エコーに「**ここで信号を読む**」
- 緩和曲線に「**この差が画像の明暗**」の寸法線。線のあいだが広いほどコントラストが大きい
- 組織は**明るさの四角つきチップ**。四角の色が、いまの条件でその組織が画像に出る明るさそのものです

## はじめて開いたとき

初回だけ、**6手のチュートリアル**が出ます。読ませるのではなく、光っているボタンを実際に押してもらう形です。

1. T1強調を押す → 2. 画像を見る（脂肪が白・水が黒） → 3. T2強調を押す → 4. **白黒が入れ替わる**
→ 5. 緩和曲線（TE の線のところの差が画像の明暗） → 6. 3D（矢印の長さが各組織の信号）

光っているボタンを押しても、カードの「次へ」でも進みます。右下の**スキップ**でいつでも抜けられ、
**Esc** でも閉じます。見たかどうかは記憶するので2回目からは出ません。
題字の横の**「使い方をもう一度」**でいつでも呼び戻せます。

画面の3つの図には **①3D ②パルスシーケンス ③緩和曲線** の番号を振ってあり、説明の中の番号と対応します。

## 配色（ライト / ダーク）

題字の横の**「ライト」「ダーク」**で切り替えられます。初回は端末の設定（`prefers-color-scheme`）に合わせ、
一度選べばその選択を覚えます。切り替えると 3D・パルスシーケンス図・緩和曲線まで一緒に色が変わるので、
**明るい部屋やプロジェクタではライト**、暗所ではダークが見やすくなります。
ライトでは線を濃いめ、ダークでは明るめに取り直していて、グラフの曲線もそれぞれ別の色を持っています。

**MR画像と断面だけはどちらの配色でも黒地のまま**です。画像は黒地で見るものなので、そこは変えていません。

## 見た目（Apple風・試作）

題字の横の **「Apple風にする」** で、見た目を Apple（iOS / macOS）の画面に寄せた試作に切り替えられます。
もう一度押すと元の見た目に戻ります。選んだほうはブラウザに保存されます。
URL の最後に `?ui=apple`（または `?ui=classic`）を付けても選べます。

- 字はシステムフォント（Mac / iPhone では SF Pro とヒラギノ）で、字間を詰めない
- 枠線をやめ、角丸の白い面（ダークでは濃い灰色）と薄い影で区切る
- 切り替えは iOS のセグメント（灰色の溝に白いつまみ）、チェックは iOS のスイッチ
- 強調色は systemBlue の1色。RF・撮影だけオレンジ
- 3D の上に浮かぶもの（今の状態・ラベル・案内カード）はすりガラス

中身（シミュレーション・文章・3D）は同じで、CSS の上書き（`html[data-ui="apple"]`）だけで作っています。

## 3D の見方

- **細い矢印** — アイソクロマット（同じ共鳴周波数をもつスピンの集まり）1つ1つの磁化。色は**位相**で、
  ばらけるほど虹色に開きます。矢印が短くなるのが T2、扇が開くのが T2′（磁場の不均一）です。
- **太い水色の矢印 M** — 全部の和。実際に信号になるのはこれの横成分だけです。
- **緑（Mz）と赤（Mxy）** — M を縦成分と横成分に分けたもの。90°パルスで緑が赤に移り、T1 で緑が戻り、T2 で赤が消えます。
- **オレンジの矢印 B₁** — RFをかけている最中だけ出ます。M はこの B₁ のまわりを回って倒れます。
- **回転座標系 / 静止座標系** — 回転座標系はラーモア周波数で一緒に回る視点。B₀ まわりの回転が止まって見えるので、
  倒れ方と減り方だけを見られます。静止座標系にすると実際に回っているようすが見えます
  （**実際の歳差は1.5Tで毎秒約6400万回。画面では見えるように大幅に遅くしています**）。
- **脳全体 / 1つのボクセル** — はじめは「脳全体」で開きます。「脳全体」では、Colin 27 から作った頭皮・脳・脳室の立体の中に、画像と同じ高さの断面が入り、
  脂肪・白質・灰白質・脳脊髄液（病変を追加したときは病変も）の場所に、**その組織の合計の磁化 M の矢印**が立ちます。どの矢印も同じパルスで同時に倒れますが、
  T1・T2 が違うので戻り方・減り方が組織ごとに違います。**断面の明るさは、その場所の組織の横磁化（矢印の横向きの長さ）×プロトン密度**で、
  時間とともに変わり、**エコーの瞬間に右の画像と同じ明暗**になります。拡大すると、選んでいるボクセルの細い矢印（アイソクロマット）に切り替わります。
  オレンジの円錐は鼻で、腹側の目印です。画像をクリックするとその画素の組織を選べます。

- **エコーで止める**（3D の下、はじめから入）— 撮像条件を変えると定常状態まで一気に計算し（ダミースキャンにあたる）、すべてのシーケンスでエコー（信号を読む瞬間）で自動的に止まります。脳全体の磁化ベクトルの長さと数字は、横磁化 × プロトン密度（＝画像の明るさ）です。
- **t = ◯ ms で止める**（3D の下） — 次の周期のその時刻で止め、縦磁化 Mz と横磁化 Mxy を読めます（例：IR で TI に合わせると 90°パルス直前の縦磁化）。
- **自由な組織** — 「3D で見ている組織」で「自由な組織」を選ぶと、T1・T2・プロトン密度を自分で決めて（数字でも入力できます）、その矢印の動きを見られます
  （画像には出ません。T1 は静磁場を変えても変わりません）。
- **フリップ角と信号のグラフ**（GRE のとき、α のつまみの下） — いまの TR・TE で、組織ごとの信号がフリップ角でどう変わるかと、
  選んでいる組織のエルンスト角（cos α = e^(−TR/T1)、信号が最大になる角度）を示します。
- **GRE でスポイラを入れる**（詳細タブ） — 外すと、前の TR の横磁化が次の TR に残ります（TR が T2 より短いと定常状態になる）。
  このときの画像は、組織ごとの矢印の直近のエコーの高さから描きます。

3D はドラッグで回転、ホイール（2本指）で拡大縮小、ダブルクリック（ダブルタップ）で視点が戻ります。

## 画像について

画像は**実写ではありません**。頭部の組織の地図は、公開のデジタル脳ファントム [Colin 27 の高解像度版（2008）](https://www.bic.mni.mcgill.ca/ServicesAtlases/Colin27Highres)（離散の組織分類、0.5 mm）の軸位断
（側脳室の体部の高さ）を使い、画素ごとの組織の T1・T2・プロトン密度から信号の式で濃度を与えています。
Colin 27 は、BrainWeb の脳ファントムの元になった、同じ健康な成人を何度も撮影して平均した脳です。
はじめは 6 組織（脂肪・白質・灰白質・脳脊髄液・筋肉・皮質骨）だけです。Colin 27 は正常脳で病変がないので、「詳細」タブの「＋ 病変（浮腫）を追加」を押したときだけ、側脳室のまわりの白質に病変（浮腫）を 3 つ描き足します。
断面の取り出し方は `tools/colin27_slice.py`。

「詳細」タブの**断面**で、横断・冠状断・矢状断を選び、位置（Talairach 座標の mm）を動かせます。断面は Colin 27 の組織分類を
1.5 mm の格子にまとめた立体（`head3d.js`、作り方は `tools/colin27_volume.py`）から切り出します。病変（浮腫）は立体の中に楕円体で置いています。
国家試験の画像問題では、問題の画像と同じ向き・高さにしてから、撮像法や TR・TE を変えて見え方を比べられます。

「詳細」タブの**頭部の画像**で、以前の簡易図形（頭部の軸位断を数式で組み立てたもの）にいつでも戻せます。選んだものはブラウザに保存されます。URL の最後に `?phantom=simple`（または `?phantom=colin27`）を付けても選べます。

**画像をクリックすると、その組織のプロトンが 3D に出ます。** 脳室をクリックして T1強調にすると、
「T1が4000msもあるから TR 500ms ではほとんど戻れず、暗い」ことがそのまま見えます。

「撮影」を押すとその条件の画像が下に並びます。T1強調・プロトン密度・T2強調・FLAIR・STIR と続けて撮ると、
同じ断面の見え方の違いを横に並べて比べられます。

## モデルの考え方

1ボクセル分のスピンを 241 本のアイソクロマットとして持ち、Bloch 方程式の解析解をそのまま時間発展させています。

- **自由歳差** — 横磁化は `exp(-Δt/T2)` で短くなり、位相は各自の Δω だけ回る。縦磁化は `1-(1-Mz)exp(-Δt/T1)`。
- **RFパルス** — 全アイソクロマットを x′ 軸（または y′ 軸）まわりに α 回す。
- **スポイラ**（GRE の TR の終わり） — 位相の傾斜をかけて見せたうえで、残りの横磁化を 0 にする（RF スポイリングまで含めた完全なスポイリング）。
- **クラッシャー** — SE・IR の TR の終わりに、残った横磁化を 0 にする。脳脊髄液のように T2 が長い組織で、前の TR の横磁化が次のエコーに混ざらないようにするため。

Δω は静磁場の不均一を表し、ローレンツ分布の分位点から決めています。こうすると合成ベクトルの減り方が
ちょうど `exp(-t/T2′)` になるので、

- FID は **T2\*** で消える（`1/T2* = 1/T2 + 1/T2′`）
- 180°パルスを入れると Δω の分だけが巻き戻り、**エコーの高さは T2 だけ**で決まる

という関係が、式を仮定せずに画面の上で成り立ちます。
実際、1.5T・白質・SE・TR 2000 / TE 100 で定常状態にすると、90°直後の横磁化は 0.95（理論値 1−e^(−TR/T1) = 0.954）、
TE でのエコーは 0.27（理論値 0.271）になります。

画像の濃度は、**3D の矢印を同じ条件で何周期も動かしたときのエコーの高さと同じ値**を、閉じた式で計算しています。

| シーケンス | 信号の式 |
|---|---|
| スピンエコー | `S = ρ(1 − 2e^(−(TR−TE/2)/T1) + e^(−TR/T1))·e^(−TE/T2)` |
| グラジエントエコー | `S = ρ·sinα·(1−E1)/(1−cosα·E1)·e^(−TE/T2)·D(TE)`　（E1 = e^(−TR/T1)） |
| 反転回復 | `S = ρ\|1 − (1+Mz)e^(−TI/T1)\|·e^(−TE/T2)`、`Mz = 1 − 2e^(−(TR−TI−TE/2)/T1) + e^(−(TR−TI)/T1)` |

スピンエコーと反転回復は、180°パルスによる縦磁化の反転まで入れた厳密な式です。教科書でよく使う `S = ρ(1 − e^(−TR/T1))·e^(−TE/T2)` は、
TE が TR より十分短いときの近似です。D(TE) は静磁場の不均一による減り方で、3D と同じ 241 本のアイソクロマットの周波数のずれから求めます
（ローレンツ分布なら `e^(−TE/T2′)`。アプリでは分布の裾を切っているので、TE が短いところで数 % 違います）。

組織ごとの矢印のエコーの高さ × プロトン密度は、この式の値と一致します（SE・IR は 0.5・1.5・3.0 T の 5 条件 × 6 組織で 10⁻¹² 以内、
GRE は 3 条件で 0.02 % 以内）。

## 数値について

T1・T2 は 1.5T での教科書的な代表値です。

| 組織 | T1 (ms) | T2 (ms) | プロトン密度 |
|---|---|---|---|
| 脂肪 | 270 | 85 | 1.00 |
| 白質 | 650 | 80 | 0.70 |
| 灰白質 | 920 | 100 | 0.80 |
| 脳脊髄液 | 4000 | 2000 | 1.00 |
| 筋肉 | 870 | 45 | 0.75 |
| 病変（浮腫） | 1200 | 180 | 0.85 |
| 皮質骨 | 250 | 1 | 0.05 |

磁場強度を変えたときの T1 は `T1(B₀) = T1(1.5T) × (B₀/1.5)^n` で補正しています。n は 3T で報告されている値との比から
組織ごとに決めた指数で、脂肪 0.50・白質 0.39・灰白質 0.53・筋肉 0.70・脳脊髄液 0.05 としています。
T2 は磁場依存が小さいので固定です。

**文献によって値の幅が大きい量です。手元の教材と突き合わせてください。**
特に白質と灰白質は、T1強調で白質が明るく・T2強調とプロトン密度で灰白質が明るくなるという
**順序**が合うように選んだ組み合わせで、数値そのものを主張するものではありません。

シミュレーションであり、診断や臨床判断に用いるものではありません。

## スマートフォン

幅 900px 以下では 1 列に積み替わり、**3D が画面の上に貼り付いたまま**コンソールだけがスクロールします。

横向きにすると左右 2 列に切り替わります。問題タブだけは 3D を貼り付けず、画面全体を設問に使います。

## 操作の細かいところ

- コンソールは幅を変えたり、画面から分離して 3D の上に浮かせたりできます（幅 900px 以上）。配置は保存されます。**Esc** で戻せます。
- 3D を**ダブルクリック**すると視点が初期位置に戻ります。
- 「最初から」でその周期の頭（熱平衡）に戻します。「一時停止」で止めて、じっくり回して見られます。
- パルスシーケンス図の時間軸は、パルスとエコーの周辺だけを拡大し、残りを `//` の折れ目で縮めています。
  そうしないと TR 9000ms のときに全部が左端に固まって読めないためです。

# MRI スピン3Dシミュレーター

### ▶ **[https://itosky79.github.io/MRI/](https://itosky79.github.io/MRI/)**

ブラウザで開くだけで使えます。インストールもログインも要りません。スマートフォンでも動きます。

---

T1強調画像・T2強調画像が「なぜそう写るのか」を、体の中のプロトンのスピンまで戻って追えるシミュレーターです。
静磁場の中で歳差運動しているスピンに **どういう力（RFパルス）を、どのタイミングでかけるか** を決めると、
そのスピンがどう倒れ・どうばらけ・どう戻るかが 3D で動き、その結果できあがる画像が横に出ます。

`index.html` と `three.min.js` の 2 ファイルを同じ場所に置いて、`index.html` をブラウザで開くだけで動きます。
three.js は CDN から読まずに同梱しているので、外部への通信は一切必要ありません。

## 画面の構成

大事な図は3つで1組です。この3つがスクロールなしで同時に見えるように並べてあります。

- **① 3D** — 体の中のプロトンが、いまどうなっているか
- **② パルスシーケンス** — いつ、どんな力（RFパルス）をかけているか
- **③ 緩和曲線とコントラスト** — その結果、組織の差がどこで開くか

どれか1つを変えると3つとも同時に変わります。右のコンソールで条件を決め、この3つで何が起きたかを読みます。
画像は3Dの右上に小さく出ます（「画像だけ」に切り替えれば大きく見られます）。

## 4つのタブ

- **シーケンス**（最初に開くタブ） — T1強調SE／T2強調SE／プロトン密度／T2*強調GRE／T1強調GRE／STIR／FLAIR／強いT2強調 を1押しで切り替えます。
  プリセットの下に **TR と TE のつまみ**があり、動かすとその場で3つの図と画像が変わります。
  使わないつまみ（IR のときだけの TI、GRE のときだけの α）は並びません。
- **学習** — ①静磁場の中のプロトン → ②合成すると1本のベクトル → ③RFパルスで倒す → ④横磁化だけが信号になる →
  ⑤T2 → ⑥T2* → ⑦スピンエコー → ⑧T1 → ⑨TRとTEで画像が変わる → ⑩反転回復、の10段。
  ステップを押すとシミュレーターがその話に必要な条件に自動で切り替わり、説明と式が出ます。「順に再生」で順番に流せます。
- **詳細** — シーケンスの種類（SE / GRE / IR）、静磁場強度（0.5 / 1.5 / 3.0 T）、静磁場のムラ（T2′）、
  そして**手でパルスをかける**ボタン。手動にすると自由歳差だけが進むので、
  **90° → 少し待つ → 180°** と押して、自分の手でスピンエコーを作れます。
- **問題** — MRIの基本を確かめる練習問題。**このアプリで作成した自作問題で、国家試験の過去問ではありません。**
  手元の過去問は「問題を入れ替える」から貼り付けて差し替えられます。「設定」を書いておくと、
  その問題を開いた瞬間にシミュレーターが同じ撮像条件になります。

## 初学者向けの手当て

- 3Dの下に**色の凡例**（細い矢印＝スピン1本ずつ・太い矢印＝合計の磁化 M・緑＝Mz・赤＝Mxy）
- 3Dの左下に「**いま何が起きているか**」を一文で表示（90°パルスで倒している／位相がばらけて信号が減っていく／エコー：ここで信号を読む など）
- パルスシーケンス図のRFに「**倒す**」「**位相をもどす**」「**縦磁化を反転**」、エコーに「**ここで信号を読む**」
- 緩和曲線に「**この差が画像の明暗**」の寸法線。線のあいだが広いほどコントラストが大きい
- 組織は**明るさの四角つきチップ**。四角の色が、いまの条件でその組織が画像に出る明るさそのものです

## 3D の見方

- **細い矢印** — アイソクロマット（同じ共鳴周波数をもつスピンの集まり）1つ1つの磁化。色は**位相**で、
  ばらけるほど虹色に開きます。矢印が短くなるのが T2、扇が開くのが T2′（磁場の不均一）です。
- **太い水色の矢印 M** — 全部の和。実際に信号になるのはこれの横成分だけです。
- **緑（Mz）と赤（Mxy）** — M を縦成分と横成分に分けたもの。90°パルスで緑が赤に移り、T1 で緑が戻り、T2 で赤が消えます。
- **オレンジの矢印 B₁** — RFをかけている最中だけ出ます。M はこの B₁ のまわりを回って倒れます。
- **回転座標系 / 静止座標系** — 回転座標系はラーモア周波数で一緒に回る視点。B₀ まわりの回転が止まって見えるので、
  倒れ方と減り方だけを見られます。静止座標系にすると実際に回っているようすが見えます
  （**実際の歳差は1.5Tで毎秒約6400万回。画面では見えるように大幅に遅くしています**）。
- **体（ボクセルの位置）を出す** — カメラが引いて、頭部の中のどこを見ているかが出ます。オレンジの円錐は鼻で、腹側の目印です。
  画像をクリックするとその画素のところにボクセルが移ります。

3D はドラッグで回転、ホイール（2本指）で拡大縮小、ダブルクリック（ダブルタップ）で視点が戻ります。

## 画像について

画像は**実写ではありません**。頭部の組織の地図は、公開のデジタル脳ファントム [Colin 27 の高解像度版（2008）](https://www.bic.mni.mcgill.ca/ServicesAtlases/Colin27Highres)（離散の組織分類、0.5 mm）の軸位断
（側脳室の体部の高さ）を使い、画素ごとの組織の T1・T2・プロトン密度から信号の式で濃度を与えています。
Colin 27 は、BrainWeb の脳ファントムの元になった、同じ健康な成人を何度も撮影して平均した脳です。
正常脳なので病変がなく、側脳室のまわりの白質に病変（浮腫）を 3 つ描き足しています。
断面の取り出し方は `tools/colin27_slice.py`。

「詳細」タブの**頭部の画像**で、以前の簡易図形（頭部の軸位断を数式で組み立てたもの）にいつでも戻せます。選んだものはブラウザに保存されます。URL の最後に `?phantom=simple`（または `?phantom=colin27`）を付けても選べます。

**画像をクリックすると、その組織のプロトンが 3D に出ます。** 脳室をクリックして T1強調にすると、
「T1が4000msもあるから TR 500ms ではほとんど戻れず、暗い」ことがそのまま見えます。

「撮影」を押すとその条件の画像が下に並びます。T1強調・プロトン密度・T2強調・FLAIR・STIR と続けて撮ると、
同じ断面の見え方の違いを横に並べて比べられます。

## モデルの考え方

1ボクセル分のスピンを 241 本のアイソクロマットとして持ち、Bloch 方程式の解析解をそのまま時間発展させています。

- **自由歳差** — 横磁化は `exp(-Δt/T2)` で短くなり、位相は各自の Δω だけ回る。縦磁化は `1-(1-Mz)exp(-Δt/T1)`。
- **RFパルス** — 全アイソクロマットを x′ 軸（または y′ 軸）まわりに α 回す。
- **スポイラ** — 集団全体に大きな位相の傾斜をかけ、横磁化の和を 0 にする（大きさは変えない）。
- **クラッシャー** — SE・IR の TR の終わりに、残った横磁化を 0 にする。脳脊髄液のように T2 が長い組織で、前の TR の横磁化が次のエコーに混ざらないようにするため。

Δω は静磁場の不均一を表し、ローレンツ分布の分位点から決めています。こうすると合成ベクトルの減り方が
ちょうど `exp(-t/T2′)` になるので、

- FID は **T2\*** で消える（`1/T2* = 1/T2 + 1/T2′`）
- 180°パルスを入れると Δω の分だけが巻き戻り、**エコーの高さは T2 だけ**で決まる

という関係が、式を仮定せずに画面の上で成り立ちます。
実際、1.5T・白質・SE・TR 2000 / TE 100 で定常状態にすると、90°直後の横磁化は 0.95（理論値 1−e^(−TR/T1) = 0.954）、
TE でのエコーは 0.27（理論値 0.271）になります。

画像の濃度は、同じ物理を閉じた式にしたもので与えています。

| シーケンス | 信号の式 |
|---|---|
| スピンエコー | `S = ρ(1 − e^(−TR/T1))·e^(−TE/T2)` |
| グラジエントエコー | `S = ρ·sinα·(1−E1)/(1−cosα·E1)·e^(−TE/T2*)`　（E1 = e^(−TR/T1)） |
| 反転回復 | `S = ρ\|1 − 2e^(−TI/T1) + e^(−TR/T1)\|·e^(−TE/T2)` |

スピンエコーの式は教科書でよく使われる簡略形です。180°パルスによる縦磁化の反転まで入れた
`1 − 2e^(−(TR−TE/2)/T1) + e^(−TR/T1)` のほうが厳密で、**3D の側はこちらと同じ振る舞い**をします
（TE ≪ TR ならどちらもほぼ同じ値です）。

## 数値について

T1・T2 は 1.5T での教科書的な代表値です。

| 組織 | T1 (ms) | T2 (ms) | プロトン密度 |
|---|---|---|---|
| 脂肪 | 270 | 85 | 1.00 |
| 白質 | 650 | 80 | 0.70 |
| 灰白質 | 920 | 100 | 0.80 |
| 脳脊髄液 | 4000 | 2000 | 1.00 |
| 筋肉 | 870 | 45 | 0.75 |
| 病変（浮腫） | 1200 | 180 | 0.85 |
| 皮質骨 | 250 | 1 | 0.05 |

磁場強度を変えたときの T1 は `T1(B₀) = T1(1.5T) × (B₀/1.5)^n` で補正しています。n は 3T で報告されている値との比から
組織ごとに決めた指数で、脂肪 0.50・白質 0.39・灰白質 0.53・筋肉 0.70・脳脊髄液 0.05 としています。
T2 は磁場依存が小さいので固定です。

**文献によって値の幅が大きい量です。手元の教材と突き合わせてください。**
特に白質と灰白質は、T1強調で白質が明るく・T2強調とプロトン密度で灰白質が明るくなるという
**順序**が合うように選んだ組み合わせで、数値そのものを主張するものではありません。

シミュレーションであり、診断や臨床判断に用いるものではありません。

## スマートフォン

幅 900px 以下では 1 列に積み替わり、**3D が画面の上に貼り付いたまま**コンソールだけがスクロールします。
条件を切り替えたときのスピンの動きを、ボタンを押しながらそのまま見られます。
横向きにすると左右 2 列に切り替わります。問題タブだけは 3D を貼り付けず、画面全体を設問に使います。

## 操作の細かいところ

- コンソールは幅を変えたり、画面から分離して 3D の上に浮かせたりできます（幅 900px 以上）。配置は保存されます。**Esc** で戻せます。
- 3D を**ダブルクリック**すると視点が初期位置に戻ります。
- 「最初から」でその周期の頭（熱平衡）に戻します。「一時停止」で止めて、じっくり回して見られます。
- パルスシーケンス図の時間軸は、パルスとエコーの周辺だけを拡大し、残りを `//` の折れ目で縮めています。
  そうしないと TR 9000ms のときに全部が左端に固まって読めないためです。

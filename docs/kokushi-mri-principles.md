# 診療放射線技師国家試験：MRI の原理を問う問題の一覧

第69回（2017年）〜第78回（2026年）の10回分から、MRI の**原理**を問う問題を集めました。
画像の解剖を答える問題、臨床の判断、造影剤の使い方、安全管理・精度管理だけの問題は外しています。

- **出典**：厚生労働省が公開している問題 PDF と正答表（下の「出典」）。正答は正答表どおりです。
- **書き方**：問題文はそのまま写さず、「何を問うか」と「正答の要点」だけを書いています。授業や教材に使うときは、必ず原本の問題と選択肢を確かめてください。
- **数字の確認**：第69〜74回の PDF の一部では、数字が文字として取り出せませんでした。その問題は原本のページを画像にして読み、数字を確かめています。
- **「第◯章」**：このシミュレーターの学習コースで、関係する章です。

## 7. 拡散・BOLD・MRA・MT・灌流・MRS

| 回・問 | 何を問うか | 正答の要点 |
|---|---|---|
| 第70回 午前16 | 拡散強調像の誤り | 「b 値は MPG パルスの間隔を示す」が誤り |
| 第71回 午後22 | 拡散強調像の正誤（2つ） | 脂肪抑制を併用する。組織の T2 値の影響を受ける |
| 第73回 午前19 | b 値が大きくなる条件（2つ） | MPG の強度 G を上げる。MPG の印加時間 δ を延ばす |
| 第75回 午後20 | 拡散強調像の誤り | 「水分子の動きが大きいほど信号が上がる」が誤り |
| 第77回 午後4 | 拡散強調像の正誤（2つ） | T2 値の影響を受ける。水分子のブラウン運動を画像にしている |
| 第69回 午前17 | BOLD 法の fMRI（2つ） | 統計解析が必要。デオキシヘモグロビン濃度が信号に影響する |
| 第72回 午後21 | BOLD 効果にいちばん鋭敏な撮影法 | EPI |
| 第74回 午後17 | fMRI で解析する信号源 | BOLD による磁化率効果 |
| 第72回 午後24 | fMRI の正誤 | 神経活動に伴う血流の変化を画像にしている |
| 第71回 午後24 | fMRI の正誤 | 運動野を描くには指先の運動を行う |
| 第70回 午前17 | TOF 法 MRA で血管内の信号が下がる原因（2つ） | 渦流と乱流 |
| 第70回 午後16 | TOF 法 MRA の正誤 | 基本のシーケンスは GRE 法 |
| 第71回 午後10 | MRA の正誤 | 造影 MRA は目的の血管に合わせて撮影時刻を決める |
| 第71回 午前16 | TOF MRA で脳実質の信号を抑えるパルス | MT パルス |
| 第74回 午前19 | MT パルスを足すと起こること（2つ） | SAR が増える。脳実質の信号が下がる |
| 第70回 午前19 | 白質の神経路の走行を推定する方法 | DTI |
| 第74回 午前20 | 灌流の情報が得られる方法（2つ） | ASL と DSC |
| 第77回 午前2 | MRI と関連事項の組合せ | 非造影の灌流 MRI と ASL |
| 第69回 午後16・第76回 午後18 | 代謝の情報が得られる方法（同じ問題が2回） | MR スペクトロスコピー |

| 回・問 | 何を問うか | 正答の要点 |

| 第70回 午前12 | MRI 装置の誤り | 「QD コイルは傾斜磁場コイルの一つ」が誤り |
